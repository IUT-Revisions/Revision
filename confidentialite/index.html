Politique de confidentialité

Mise à jour : 23 novembre 2026

1. Sans compte

Toutes les révisions de GabouLearn sont utilisables sans compte. Ta progression dans les parcours, tes notes saisies dans le calculateur et ton plan restent uniquement dans ton navigateur (stockage local) : rien n'est envoyé. Le relevé de notes PDF que tu importes est lu dans ton navigateur et n'est jamais transmis. Le site n'utilise ni publicité, ni traceur, ni outil de mesure d'audience.

2. Avec un compte

Les comptes sont réservés aux étudiants d'Aix-Marseille Université (adresse @etu.univ-amu.fr). Ils servent à réserver certaines fonctions aux étudiants de l'IUT et à protéger le site.

Base légale : intérêt légitime (sécurité du service, accès réservé aux étudiants AMU) et ta demande de création de compte.

Hébergement : les comptes sont gérés par Supabase (base de données hébergée dans l'Union européenne). Le site lui-même est hébergé par GitHub Pages.

Qui y a accès : uniquement l'administrateur de GabouLearn. Aucune donnée n'est vendue ni transmise à des tiers.

3. Tes droits

  • Effacement : tu peux supprimer ton compte toi-même depuis Mon compte. Ton adresse est alors effacée, y compris du journal (seul un événement anonyme « suppression de compte » est conservé).
  • Accès, rectification, opposition : demande-les via le dépôt GitHub de GabouLearn (sans y publier de donnée personnelle : on te recontactera).
  • Réclamation : tu peux saisir la CNIL (cnil.fr).
