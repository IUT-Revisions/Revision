1. Arithmétique modulaire

  • Division euclidienne : a = bq + r, 0 ≤ r < b. PGCD par Euclide : 640 = 520 + 120 ; 520 = 4×120 + 40 ; 120 = 3×40 → PGCD = 40.
  • On réduit avant de calculer : 7 ≡ 2 (mod 5), 2⁴ ≡ 1, donc 7^2021 = 7^(4×505+1) ≡ 2.
  • a a un inverse modulo n ⇔ PGCD(a, n) = 1 (Bézout : au + nv = 1). Inverse de 3 mod 7 = 5.
  • Fermat : p premier, a non multiple de p ⇒ a^(p−1) ≡ 1 (mod p).

3. RSA, Diffie-Hellman, Hamming

  • RSA : n = pq, φ = (p−1)(q−1), e premier avec φ, d = e⁻¹ mod φ. c = mᵉ mod n ; m = cᵈ mod n. Exemple p = 3, q = 11, e = 3 → n = 33, φ = 20, d = 7 ; m = 4 → c = 31.
  • Diffie-Hellman : p, g publics ; A = gᵃ mod p, B = gᵇ mod p ; secret commun gᵃᵇ mod p. Sans authentification : homme du milieu.
  • Hamming (7,4) : 4 bits utiles, 3 de contrôle, distance 3 : corrige 1 erreur, en détecte 2. Bit de parité : détecte un nombre impair d'erreurs.
