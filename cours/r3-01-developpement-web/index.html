2. HTTP, sessions, MVC

  • HTTP est sans état ; HTTPS = HTTP dans TLS. GET pour lire (paramètres dans l'URL), POST pour modifier (corps).
  • Codes : 200 OK, 301/302 redirection, 400/401/403/404 erreurs du client, 500 erreur du serveur.
  • Session : données côté serveur, retrouvées grâce à l'identifiant du cookie (PHPSESSID).
  • MVC : Modèle = données et règles ; Vue = affichage ; Contrôleur = reçoit la requête et orchestre.
