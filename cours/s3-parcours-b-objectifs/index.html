3. Réseaux : DHCP, NAT, IPv6

DHCP

DORA : Discover (broadcast, source 0.0.0.0) → Offer → Request → Ack. UDP 67 serveur, 68 client.

Serveur dans un autre réseau : relais sur le routeur (ip helper-address).

Cisco : ip dhcp excluded-address, puis ip dhcp pool → network, default-router, dns-server.

NAT / PAT

Privé RFC 1918 : 10/8, 172.16/12, 192.168/16.

Statique 1↔1 (publier un serveur) · dynamique (pool) · PAT (une IP publique, les ports départagent).

ip nat inside / ip nat outside sur les interfaces, puis ip nat inside source list 1 interface g0/1 overload.

IPv6 : préfixeTypeÀ retenir
fe80::/10Lien localSur chaque interface, ne passe pas les routeurs. La passerelle par défaut est l'adresse lien local du routeur.
fc00::/7 (fd…)Locale unique (ULA)L'équivalent du privé IPv4.
2000::/3GlobaleRoutable sur Internet (2a00:…, 2001:…).
ff00::/8MulticastRemplace le broadcast : ff02::1 tous les nœuds, ff02::2 tous les routeurs.

Le piège classique

SLAAC = le routeur seul (RA avec le préfixe). SLAAC + DHCPv6 sans état : le serveur ne donne que les DNS. DHCPv6 avec état (drapeau M) : le serveur donne l'adresse. La passerelle vient toujours du RA. Compression : « :: » une seule fois ; EUI-64 : FF:FE au milieu et 7e bit inversé (84 → 86).

4. R3.05 Programmation système

Fichiers & Makefiles

Descripteurs 0/1/2. open → -1 si erreur ; read → nb d'octets, 0 = fin. Inode : tout sauf le nom.

cible: dépendances + TAB commande. $@ cible, $< 1re dépendance, $^ toutes. .PHONY.

Processus & signaux

fork : 0 fils / PID fils au père / -1. exec remplace, garde le PID. wait évite les zombies.

kill(pid, sig) ; SIGKILL et SIGSTOP impossibles à capter ; SIGCHLD au père ; sigaction.

Sockets TCP en C

Serveur : socket → bind → listen → accept ; client : socket → connect. htons(port), INADDR_ANY, une nouvelle socket par accept, SO_REUSEADDR contre « Address already in use ». HTTP/0.9 : GET /chemin, pas d'en-têtes.
