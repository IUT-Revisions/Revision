1. Fonctions et curseurs PL/pgSQL

CREATE OR REPLACE FUNCTION nb_cmd(p_client INT) RETURNS INT AS $$
DECLARE n INT;
BEGIN SELECT COUNT(*) INTO n FROM commande WHERE client = p_client; RETURN n; END;
$$ LANGUAGE plpgsql;

Variables : %TYPE, %ROWTYPE, RECORD. Parcours : curseur (OPEN / FETCH / CLOSE) ou FOR rec IN SELECT … LOOP … END LOOP. Erreur métier : RAISE EXCEPTION 'message' ; message simple : RAISE NOTICE.
